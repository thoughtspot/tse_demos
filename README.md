Repo consisting of projects on Thoughtspot Everywhere including Claude Skills to build a custom portal.

## Claude skills

- [`rebrand-thoughtspot-portal`](.claude/skills/rebrand-thoughtspot-portal/SKILL.md) is a guided interview. It white-labels a portal on top of ThoughtSpot content you already have.
- [`bespoke-thoughtspot-portal`](.claude/skills/bespoke-thoughtspot-portal/README.md) starts from just a company website. It builds the synthetic dataset, the Snowflake table, the Model, the Liveboard, a custom chart and the portal. See its README for install steps.
